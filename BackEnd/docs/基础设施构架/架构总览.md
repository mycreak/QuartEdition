# 架构总览

> QuartEdition — 豆瓣电影数据采集与管理系统

---

## 一、核心工作流

```
管理员提交任务（类型+评分区间）
  → 限速写入 Redis ZSET（防瞬时并发）
  → Puller 每 0.1s 从 ZSET 弹出到期任务 → asyncio.Queue
  → 5 个 Worker 协程抢任务 → Worker 执行前随机 2~5min jitter（反爬错峰）
  → CrawlerEngine 按 type 分发：
      movie_crawl → ApiFetcher(aiohttp) → 榜单 API → douban_ids 表
      movie_scrape_task → BrowserFetcher(Playwright) → 详情页（原子事务入库）
        └─ 成功后自动 ZADD director_crawl 子任务
      director_crawl → BrowserFetcher → celebrities 页 → 演职人员（原子事务入库）
      review_crawl / comment_crawl → BrowserFetcher → MongoDB
  → 成功 → WorkerEvent(SUCCESS) → task_history=done
  → 失败 → WorkerEvent(FAILURE) → task_failures 表（scope=batch/item）
  → Monitor 每 10s 汇总事件 → 日志报告 + WS 推送到前端仪表盘
```

## 二、技术栈

| 层 | 技术 | 用途 |
|------|------|------|
| HTTP 框架 | Quart（异步 Flask） | REST API |
| 异步引擎 | Python asyncio | 全链路非阻塞 |
| 浏览器 | Playwright Chromium headless | 爬取受 SHA-512 保护的豆瓣页面 |
| HTTP 客户端 | aiohttp | JSON API + 轻量页面 |
| 数据库 | MySQL 8.0 + MongoDB 7.0 + Redis 7.0 | 关系 / 文档 / 缓存+延迟队列 |
| 配置 | pydantic-settings | 环境变量 |
| 进程管理 | hypercorn | ASGI server |

## 三、数据存储

| 数据库 | 存储内容 |
|------|------|
| **MySQL** | users / permissions / user_permissions / movies / people / movie_credits / movie_genres / movie_ratings / regions / crawl_progress / douban_ids / task_history / task_failures |
| **MongoDB** | reviews（长评）/ comments（短评） |
| **Redis** | 延迟队列 ZSET（crawler:delay_queue）+ API 限速 Lua 脚本 |

## 四、多进程架构

```
hypercorn 主进程
  ├─ before_serving:
  │   init_mysql(MIN=5, MAX=20)
  │   init_redis()
  │   init_mongo_client()
  │   init_auth_service()
  │   init_cookie_manager()          ← P0 2026-05-10 新增：多账号 Cookie 管理
  │   init_crawler(browser, movie_service)
  │   init_task_failure_service()
  │   init_task_history_service()
  │   browser_pool.start()      ← 5 Worker 协程
  │   monitor.run()             ← 后台协程
  │   puller.run()              ← 后台协程
  │   asyncio.create_task(健康检查) ← Cookie 验证等
  │
  ├─ while serving:
  │   接收 HTTP 请求 → admin_bp / auth_bp / user_bp / ws
  │
  └─ after_serving:
      puller.stop() → browser_pool.stop() → DB close → Redis close
```

## 五、路由结构

```
/auth/*         认证（login / me）
/user/*         用户端浏览（电影列表/详情/评论）
/admin/*        管理端（22 个端点 + 基础设施 6 个 + douban_id 3 个 + Cookie 6 个 = 37 个端点）
/ws/notifications  WebSocket（需要 ?token=xxx）
```

## 六、目录结构

```
BackEnd/
├── app.py                   # Quart 入口 + before_serving 初始化
├── config/                   # 配置（pydantic-settings）
├── background/               # Puller / Worker / Monitor 协程
├── crawler/                  # 爬虫引擎
│   ├── __init__.py           # CrawlerEngine 任务分发
│   ├── fetcher.py            # BrowserFetcher + ApiFetcher
│   ├── parser.py             # HTML/JSON 解析
│   ├── storage.py            # MySQL/MongoDB 写入
│   ├── proxy.py              # ProxyPool 状态机
│   ├── identity.py           # Identity + IdentityManager (P0)
│   └── cookie_manager.py     # CookieManager 多账号管理 (P0)
├── routes/
│   ├── admin/                # 管理端 (9 个子模块)
│   ├── auth.py               # 认证
│   └── user.py               # 用户端
├── services/                 # MovieService / AuthService / TaskHistoryService / TaskFailureService
├── db/                       # DatabaseLayerV2 (MySQL / MongoDB 双模式)
├── models/                   # Pydantic 请求/响应模型
├── utils/                    # JWT / SnowflakeID / 日志配置
├── scripts/                  # seed_auth.py / douban_login.py
├── data/                     # douban_storage.json / proxies.json / cookies/
└── docs/                     # 文档
```
