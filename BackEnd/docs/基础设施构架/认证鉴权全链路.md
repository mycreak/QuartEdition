# 认证鉴权全链路文档

> 注册 → bcrypt 加密密码 → 存入 MySQL
> 登录 → bcrypt 校验 → 签发 JWT(HS256, 7天, sub=user_id)
> 后续请求 → Authorization: Bearer \<token\>
>          → verify_token 解出 user_id
>          → 查 is_active 确保未禁用
>          → @require_permission 额外查 user_permissions 表

---

## 三、注册流程

### 3.1 请求

```
POST /auth/register
Content-Type: application/json

{
  "username": "alice",
  "password": "123456",
  "display_name": "爱丽丝"      // 可选，为空则取 username
}
```

### 3.2 逻辑链路

```
auth_routes.py:register()
  │
  ├─→ ① Pydantic 校验
  │     UserCreate(username=3-32位字母数字下划线, password=6-128位)
  │     @field_validator("username") 正则匹配 ^[a-zA-Z0-9_]{3,32}$
  │
  ├─→ ② AuthService.create_user(data, created_by=0)
  │     │
  │     ├─→ 查 username 唯一性
  │     │     db.find_one("users", {"username": data.username})
  │     │     存在 → raise ValueError("用户名已存在") → 409
  │     │
  │     ├─→ bcrypt 加密密码
  │     │     bcrypt.hashpw(password.encode(), gensalt(rounds=12))
  │     │     → 输出 "$2b$12$..." 哈希字符串
  │     │
  │     ├─→ INSERT INTO users (username, password_hash, display_name)
  │     │
  │     └─→ 返回 UserRead（不含 password_hash）
  │
  └─→ 返回 201
      {
        "id": 1,
        "username": "alice",
        "display_name": "爱丽丝",
        "message": "注册成功"
      }
```

### 3.3 核心代码

```python
# services/auth_service.py : create_user()
async def create_user(self, data: UserCreate, created_by: int = 0) -> UserRead:
    # 唯一性校验
    existing = await self.db.find_one("users", {"username": data.username})
    if existing:
        raise ValueError(f"用户名 '{data.username}' 已存在")

    # bcrypt 加密
    password_hash = bcrypt.hashpw(
        data.password.encode("utf-8"),
        bcrypt.gensalt(rounds=BCRYPT_ROUNDS),
    ).decode("utf-8")

    display_name = data.display_name or data.username

    # 入库
    user_id = await self.db.insert("users", {
        "username": data.username,
        "password_hash": password_hash,
        "display_name": display_name,
    })
    return await self.get_user(user_id)
```

### 3.4 注意

- **密码不存明文**：入库前必须 bcrypt 加密，即使 DB 泄露也无法反解
- **唯一性在应用层校验**：虽然有 UNIQUE 索引，但先查后插能给出更好的错误提示
- **`created_by` 保留**：未来管理员代注册时可记录操作者，当前注册都是用户自注册传 0

## 四、登录流程

### 4.1 请求

```
POST /auth/login
Content-Type: application/json

{
  "username": "alice",
  "password": "123456"
}
```

### 4.2 逻辑链路

```
auth_routes.py:login()
  │
  ├─→ ① Pydantic 校验
  │     UserLogin(username, password)
  │
  ├─→ ② AuthService.authenticate(data)
  │     │
  │     ├─→ 查 users WHERE username=
  │     │     不存在 → return None
  │     │
  │     ├─→ 校验 is_active
  │     │     is_active=0 → 日志警告 + return None
  │     │
  │     ├─→ bcrypt.checkpw(明文, password_hash 哈希)
  │     │     不匹配 → return None
  │     │
  │     └─→ 匹配 → return user raw dict（含 id, username, is_active...）
  │
  ├─→ ③ AuthService.create_token(user["id"])
  │     │
  │     ├─→ 构造 JWT payload
  │     │     {
  │     │       "sub": "1",                              // 用户 ID（字符串）
  │     │       "iat": 2026-05-06T12:00:00+00:00,        // 签发时间
  │     │       "exp": 2026-05-13T12:00:00+00:00         // 过期时间（7天）
  │     │     }
  │     │
  │     └─→ jwt.encode(payload, JWT_SECRET, algorithm="HS256")
  │            → "eyJhbGciOiJIUzI1NiIsInR5cCI6IkpXVCJ9..."
  │
  └─→ 返回 200
      {
        "token": "eyJ...",
        "user": {
          "id": 1,
          "username": "alice",
          "display_name": "爱丽丝"
        }
      }
```

### 4.3 核心代码

```python
# services/auth_service.py : authenticate()
async def authenticate(self, data: UserLogin) -> Optional[Dict[str, Any]]:
    row = await self.get_user_by_username(data.username)
    if not row:
        return None
    if not row.get("is_active"):
        logger.warning(f"尝试登录已禁用的用户: {data.username}")
        return None
    ok = bcrypt.checkpw(
        data.password.encode("utf-8"),
        row["password_hash"].encode("utf-8"),
    )
    return row if ok else None

# services/auth_service.py : create_token()
def create_token(self, user_id: int) -> str:
    now = datetime.now(timezone.utc)
    payload = {
        "sub": str(user_id),
        "iat": now,
        "exp": now + timedelta(seconds=JWT_EXPIRE_SECONDS),  # 默认 7×86400
    }
    return jwt.encode(payload, JWT_SECRET, algorithm=JWT_ALGORITHM)
```

### 4.4 注意

- **JWT 无状态**：签发后服务端不存储，无法主动失效。如需登出/封禁，依赖 `is_active` 字段
- **`sub` 使用字符串**：JWT 标准推荐，避免语言间整数精度问题
- **`JWT_EXPIRE_SECONDS` 可配**：`config/settings.py` 中集中管理

## 五、身份验证（JWT 校验）流程

### 5.1 调用入口

```
GET /user/movies                  ← 被 @require_login 装饰
Authorization: Bearer eyJ...
```

```
GET /admin/movies                 ← 被 @require_permission("movie:read") 装饰
Authorization: Bearer eyJ...
```

### 5.2 get_current_user() 详解

```
utils/auth.py:get_current_user()
  │
  ├─→ ① 提取 Authorization header
  │     header = request.headers.get("Authorization", "")
  │     if not header.startswith("Bearer "): return 0
  │     token = header[7:]         // 去掉 "Bearer "
  │
  ├─→ ② AuthService.verify_token(token)
  │     │
  │     ├─→ jwt.decode(token, JWT_SECRET, algorithms=["HS256"])
  │     │     ├─→ 签名校验失败 → raise InvalidTokenError
  │     │     ├─→ 已过期 → raise ExpiredSignatureError
  │     │     └─→ 成功 → payload["sub"] → "1"
  │     │
  │     └─→ return user_id (int) 或 None
  │
  ├─→ ③ 校验 is_active
  │     AuthService.get_user(user_id)
  │     → UserRead.is_active == False → return 0
  │
  └─→ return user_id (int)
```

### 5.3 核心代码

```python
# services/auth_service.py : verify_token()
def verify_token(self, token: str) -> Optional[int]:
    try:
        payload = jwt.decode(token, JWT_SECRET, algorithms=[JWT_ALGORITHM])
        return int(payload["sub"])
    except jwt.ExpiredSignatureError:
        return None            # token 过期
    except (jwt.InvalidTokenError, KeyError, ValueError):
        return None            # 签名无效 / 格式错误

# utils/auth.py : get_current_user()
async def get_current_user() -> int:
    header = request.headers.get("Authorization", "")
    if not header.startswith("Bearer "):
        return 0

    token = header[7:]
    svc = _get_auth_service()
    user_id = svc.verify_token(token)
    if user_id is None:
        return 0

    user = await svc.get_user(user_id)
    if not user or not user.is_active:
        return 0

    return user_id
```

### 5.4 注意

- **每次请求都查 DB（is_active）**：这是有状态的，确保封禁用户立即可用。极端高性能场景可考虑 Redis 缓存
- **`get_current_user()` 返回 0 表示未登录**：调用方通过 `if not user_id: return 401` 判断
- **`sub` 转 int**：JWT 中存储 `"1"`（字符串），返回前转 `1`（int）

## 六、鉴权（权限校验）流程

### 6.1 调用入口

```
@require_permission("movie:manage")
async def publish_movie(movie_id: int):
    ...
```

### 6.2 逻辑链路

```
utils/auth.py:require_permission("movie:manage")
  │
  ├─→ ① get_current_user()
  │     未登录 → return 401 {"error": "未登录或登录已过期"}
  │
  ├─→ ② AuthService.check_permission(user_id, "movie:manage")
  │     │
  │     ├─→ db.find_one("user_permissions", {
  │     │     "user_id": user_id,
  │     │     "permission_code": "movie:manage"
  │     │   })
  │     │
  │     └─→ 查到记录 → True, 无记录 → False
  │
  ├─→ ③ 有权限 → g.user_id = user_id → 执行 handler
  │
  └─→ 无权限 → return 403 {"error": "无权限: movie:manage"}
```

### 6.3 核心代码

```python
# services/auth_service.py : check_permission()
async def check_permission(self, user_id: int, permission_code: str) -> bool:
    row = await self.db.find_one("user_permissions", {
        "user_id": user_id,
        "permission_code": permission_code,
    })
    return row is not None

# utils/auth.py : require_permission()
def require_permission(permission_code: str):
    def decorator(func):
        @wraps(func)
        async def wrapper(*args, **kwargs):
            user_id = await get_current_user()
            if not user_id:
                return jsonify({"error": "未登录或登录已过期"}), 401

            svc = _get_auth_service()
            if not await svc.check_permission(user_id, permission_code):
                return jsonify({"error": f"无权限: {permission_code}"}), 403

            g.user_id = user_id
            return await func(*args, **kwargs)
        return wrapper
    return decorator
```

## 七、三个装饰器层级

| 装饰器 | 校验项 | 适用路由 | 失败返回 |
|--------|--------|----------|----------|
| **无** | — | `/auth/login`, `/auth/register` | — |
| **`@require_login`** | JWT + is_active | `/user/*`（浏览电影/评论/类型/过滤器） | 401 |
| **`@require_permission(code)`** | JWT + is_active + 权限编码 | `/admin/*`（22 个管理端点） | 401 或 403 |

使用示例：

```python
# 用户端——只需登录
from utils.auth import require_login

@user_bp.route("/movies")
@require_login
async def list_movies():
    ...

# 管理端——需要具体权限
from utils.auth import require_permission

@admin_bp.route("/movies/<id>/publish", methods=["POST"])
@require_permission("movie:manage")
async def publish_movie(movie_id: int):
    ...
```

## 八、数据库表结构

```sql
-- users 表
CREATE TABLE users (
    id            INT             AUTO_INCREMENT PRIMARY KEY,
    username      VARCHAR(64)     NOT NULL UNIQUE,
    password_hash VARCHAR(255)    NOT NULL COMMENT 'bcrypt 哈希',
    display_name  VARCHAR(64)     NOT NULL,
    is_active     TINYINT(1)      NOT NULL DEFAULT 1 COMMENT '1=启用 0=禁用',
    created_at    DATETIME        NOT NULL DEFAULT CURRENT_TIMESTAMP,
    updated_at    DATETIME        NULL ON UPDATE CURRENT_TIMESTAMP
) ENGINE=InnoDB DEFAULT CHARSET=utf8mb4;

-- user_permissions 表
CREATE TABLE user_permissions (
    id              INT             AUTO_INCREMENT PRIMARY KEY,
    user_id         INT             NOT NULL,
    permission_code VARCHAR(64)     NOT NULL COMMENT '如 movie:read',
    granted_by      INT             NOT NULL COMMENT '授权管理员 ID',
    granted_at      DATETIME        NOT NULL DEFAULT CURRENT_TIMESTAMP,
    UNIQUE KEY uk_user_perm (user_id, permission_code),
    FOREIGN KEY (user_id) REFERENCES users(id) ON DELETE CASCADE
) ENGINE=InnoDB DEFAULT CHARSET=utf8mb4;

-- permissions 字典表
CREATE TABLE permissions (
    code        VARCHAR(64)     PRIMARY KEY,
    name        VARCHAR(64)     NOT NULL COMMENT '权限名称',
    description VARCHAR(255)    DEFAULT '' COMMENT '权限说明'
) ENGINE=InnoDB DEFAULT CHARSET=utf8mb4;
```

> `permissions` 表存储 9 条预置权限，`user_permissions` 存用户-权限的 N:N 关联

## 十一、常见问题

### Q1: token 泄露了怎么办？
A: 无状态 JWT 无法主动失效。立刻将用户 `is_active=0` 可使其 token 即刻失效（每次请求都查 `is_active`）。

### Q2: 为什么需要 get_current_user() 每次查 DB？
A: 确保封禁实时生效。如果对性能有更高要求，可引入 Redis 缓存 `user:{id}:is_active`。

### Q3: 权限能动态添加吗？
A: 当前权限编码有 Pydantic 白名单校验（`VALID_PERMISSION_CODES`），新增权限需要同时更新白名单和 `permissions` 表。

### Q4: 密码有什么限制？
A: 用户名 3-32 位字母数字下划线，密码 6-128 位。bcrypt 自动处理哈希存储，入库后不可逆。
