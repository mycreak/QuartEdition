## 七、关键测试策略总结

### ✅ 必须测试的核心路径

1. **用户注册 → 登录 → 权限验证** - 认证鉴权全链路
2. **movie_crawl → douban_ids → movie_scrape_task → director_crawl** - 电影完整爬取流程
3. **review_crawl → review_body_crawl** - 长评分层爬取
4. **任务提交 → Puller 弹出 → Worker 执行 → 成功/失败上报** - 调度全链路
5. **WebSocket 连接 → 任务推送 → 系统状态广播** - 实时通信
6. **Cookie 多账号轮换 + 代理池切换 + 身份绑定** - 爬虫基础设施

### ⚠️ 高风险区域重点测试

1. **原子事务** - `save_movie_basic()` / `save_crew()` 的回滚逻辑
2. **乐观锁** - douban_id 认领 / 失败任务认领的竞态条件
3. **ContextVar 隔离** - DatabaseLayerV2 的 asyncio 并发安全
4. **Lua 脚本** - Redis 延迟队列的原子操作
5. **崩溃自愈** - BrowserFetcher 的浏览器重启逻辑
