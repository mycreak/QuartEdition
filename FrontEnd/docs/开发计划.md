## 二、待实现

### 优先级 P0 — douban_id 资产管理（全新页面）

**后端已就绪**（P1 已编码）：

| 方法 | 路径 | 权限 |
|------|------|------|
| `GET` | `/admin/douban-ids` | `crawler:task:read` |
| `POST` | `/admin/douban-ids` | `crawler:task:write` |
| `POST` | `/admin/douban-ids/<id>/acquire` | `crawler:task:write` |

**需要新建**：`views/admin/DoubanIdsView.vue` + `src/api/admin/doubanIds.ts`

页面功能：
- 搜索框 + 类型下拉 + 未认领过滤
- 分页列表（douban_id / title / type_num / interval_id / is_acquired / acquired_at）
- 手动添加 douban_id 弹窗
- 认领按钮（原子，先到先得 → 409 处理）

> **业务逻辑**：`movie_crawl` 任务从豆瓣榜单 API 获取 ID 后写入 `douban_ids` 表（is_acquired=0）。管理员在此页面查看、搜索、认领，然后在爬虫面板提交 `movie_scrape_task` 指定 `douban_id` + `cookie_id` + `proxy_key`。
