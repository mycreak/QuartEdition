## 二、启动流程

```
index.html → main.ts

main.ts
  ├─ app = createApp(App)
  ├─ app.use(createPinia())          ← 必须在 Router 之前
  ├─ app.use(ElementPlus, { locale: zhCn })  ← 中文包 + 分页文案覆盖
  ├─ 批量注册 Element Plus Icons     ← 全部图标全局可用
  ├─ setupGuards(router)             ← 路由守卫注册
  ├─ app.use(router)
  └─ app.mount('#app')

App.vue
  ├─ 判断路由名 Login/Register → 全屏模式（无 header）
  ├─ 判断路由 /admin/* → 标准模式但走 AdminLayout（侧边栏+顶栏）
  ├─ 否则 → 标准模式（AppHeader + router-view）
  └─ onMounted + watch(token):
       ├─ wsManager.connect(token)   ← 全局 WS 连接
       ├─ 订阅 task_failure          ← ElNotification 弹窗
       └─ 订阅 worker_crash          ← ElNotification 弹窗
```

## 四、模块依赖关系

```
src/types/          ← 纯类型层，所有模块依赖
src/utils/          ← 纯函数层，被 views/components/stores 依赖
src/api/            ← 依赖 types + utils（client.ts 读 localStorage("token")）
src/stores/         ← 依赖 api + types
src/router/         ← 依赖 stores/auth（guards 内部调用 fetchUser）
src/components/     ← 依赖 types + api + stores
src/views/          ← 依赖 components + api + stores + router
src/App.vue         ← 持有 wsManager 全局生命周期
```

**关键约束**：
- 组件**不直接调 axios**，全部通过 `src/api/` 封装
- 组件**不直接读写 localStorage**，全部通过 `authStore`
- 类型定义**只写一次**在 `src/types/`，API 封装和组件共享
- `stores/auth.ts` 的 `fetchUser()` 失败时不主动清除 token（网络断连留恢复机会），仅 401 时才清除

### 6.3 权限函数

```typescript
// authStore 提供:
isAdmin: boolean                    // computed 从 user.role
permissions: string[]               // /auth/me 返回

// utils/permission.ts 提供:
```

- **路由级**：`route.meta.permission` → `guards.ts` `beforeEach` 拦截 → 无权限跳 `/403`

- **侧边栏**：`AdminLayout.vue` 按权限动态渲染菜单项
- **InfraView.vue** 内部 Tab 也按 `infra:proxy:read` / `infra:cookie:read` 控制可见

## 七、认证流程

```
① 用户输入密码登录
  → POST /auth/login → { token, user: { id, uuid, username, display_name, avatar_url, permissions } }
  → localStorage.set('token')
  → authStore.fetchUser() → GET /auth/me → 填充 user 对象
  → router.push('/')

② 页面刷新 / 新标签页
  → beforeEach 守卫
  → localStorage 有 token?
    → GET /auth/me → 填充 authStore.user + permissions → 放行
  → 无 token?
    → 目标路由需登录? → 跳 /login（带 redirect query）
    → 公开路由? → 直接放行

③ 401 拦截（api/client.ts 响应拦截）
  → localStorage.removeItem('token')
  → authStore.$reset()
  → window.location.href = '/login'
  → 排除 /auth/login 和 /auth/register 避免循环

④ 个人中心头像/昵称更新
  → ProfileView / AdminProfileView → AvatarUpload 上传 → PATCH /auth/me
  → authStore.updateProfile(newUser) → 合并 store.user
  → AppHeader / AdminLayout 头像和昵称即时刷新
```

## 九、状态管理（Pinia）

### 9.1 authStore（src/stores/auth.ts）

```typescript
// 组合式风格
state:
  user: User | null          // 当前登录用户（含 avatar_url / permissions / role）
  token: string | null       // localStorage 同步

getters:
  isAdmin: boolean           // user.role === 'admin'
  isLoggedIn: boolean        // !!token

actions:
  login(credentials)         // POST /auth/login → 存 token → fetchUser()
  register(data)             // POST /auth/register
  fetchUser()                // GET /auth/me → 填充 user
  logout()                   // 清除 token + user
  checkPermission(code)      // 委托 hasPermission()
  updateProfile(newUser)     // 合并 user 对象（头像/昵称更新后）
```

```typescript
// 组合式风格
state:
```

## 十、WebSocket 通信

### 10.1 架构

```
┌─────────────────────────────────────────────────────────────────┐
│  WsManager（src/api/ws.ts）— 全局单例                            │
│                                                                  │
│  端点：ws://localhost:8000/ws/notifications?token=<JWT>          │
│                                                                  │
│  特性：                                                          │
│    · 心跳 ping/pong 每 30s                                       │
│    · 断线指数退避重连（1s → 2s → 4s → ... → max 30s）           │
│    · on(type, handler) 注册回调，返回 unsubscribe 函数            │
│    · connect(token) / disconnect() 生命周期管理                   │
└─────────────────────────────────────────────────────────────────┘
```

### 10.2 事件类型与消费

| 事件类型 | 推送范围 | 订阅位置 | 前端行为 |
|----------|---------|---------|---------|
| `system_status` | 全体广播（每 10s） | `DashboardView.vue` | 1s 节流后更新 7 张状态卡片 + 队列面板 |
| `task_failure` | 按 admin_id | `App.vue` | 管理端 → `ElNotification`（红色，手动关闭）；非管理端 → 积压数组 |
| `worker_crash` | 全体广播 | `App.vue` | `ElNotification`（黄色，手动关闭） |
| `task_progress` | 按 admin_id | `DashboardView.vue` | 更新执行中表格 `stage` 列 |

### 10.3 调试工具

仪表盘底部「🛠️ 调试工具」卡片（`system:monitor` 权限可见）：

## 十四、开发约定

| 约定 | 说明 |
|------|------|
| 组件命名 | 页面 `XxxView.vue`，通用组件 `XxxXxxx.vue`，布局 `XxxLayout.vue` |
| `<script setup>` | 全部使用 Composition API + `<script setup lang="ts">` |
| 类型导入 | `import type { ... }` 避免运行时导入 |
| API 调用 | 必须通过 `src/api/` 封装，禁止组件内直接 `axios.get` |
| token 管理 | 必须通过 `authStore`，禁止直接读 `localStorage.getItem("token")` |
| 路由懒加载 | `component: () => import(...)`，无例外 |
| 响应式 | 简单类型用 `ref`，对象/数组用 `reactive`，跨组件共享用 `store` |
| 环境变量 | `VITE_API_BASE_URL` / `VITE_WS_URL`，开发/生产分文件 |
| 权限检查 | 路由级：`route.meta.permission`；按钮级：`v-if="authStore.checkPermission('xxx')"` |
