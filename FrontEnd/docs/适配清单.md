## 四、WebSocket 事件

### 4.1 后端 WS 端点

```
/ws/notifications?token=<JWT>
```

### 4.2 事件类型

| 类型 | 推送范围 | 前端行为 | 适配文件 |
|------|---------|---------|---------|
| `system_status` | 全体广播 | DashboardView 卡片实时刷新（1s 节流） | DashboardView.vue |
| `task_failure` | 按 admin_id 推送 | App.vue 全局 ElNotification（error，手动关闭）；非管理端积压 → 进入 /admin 批量弹出 | App.vue |
| `task_success` | 按 admin_id 推送 | 已预留 | — |
| `worker_crash` | 全体广播 | App.vue 全局 ElNotification（warning，手动关闭） | App.vue |
| `task_progress` | 按 admin_id 推送 | DashboardView / TasksView 进度 Tab 实时更新 in_flight.stage | DashboardView.vue / TasksView.vue |

### 4.3 WsManager（全局单例）

```typescript
wsManager.connect(token)    // 建立连接
wsManager.disconnect()      // 断开
wsManager.on(type, handler) // 注册回调，返回 unsubscribe 函数
wsManager.status            // 'disconnected' | 'connecting' | 'connected'
```

- 心跳：每 30s 发送 ping
- 重连：指数退避（1s→2s→4s→8s→max 30s）
- 单例：由 App.vue 持有生命周期

## 六、用户管理

| 操作 | 端点 | 安全措施 |
|------|------|---------|
| 创建用户 | `POST /admin/users` | 表单校验（密码复杂度） |

## 七、修复记录

| 问题 | 根因 | 修复 |
|------|------|------|
| 登录提示"网络连接失败" | LoginResponse 类型断言 `permissions` 导致崩溃 | 回退为存 token + fetchUser |
| 禁用用户显示"密码错误" | UserDisabledError code 未重写，返回 UNAUTHORIZED | self.code = "USER_DISABLED" |
| 失败任务分页 total=0 | 后端 list 接口没做 COUNT；前端写死 total=0 | 后端加 COUNT，前端读 total |
| 自禁用未拦截 | authStore.user?.id 是 undefined（API 返回 uuid） | 改用 username 比对 |
| crawl_progress 空行 | total=0 且 type_name 为空的行被渲染 | 过滤 r.total > 0 \|\| r.type_name |
